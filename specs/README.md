# Slide specs and reviews

Committed outputs written by Opus sessions (D10): `<ID>.spec.json` (WP 2.3) and `<ID>.review.json` (WP 4.1). They cannot be regenerated by the CLI, so they live here, not in gitignored `data/`.

`drafts/` holds partial specs, such as the WP 2.2 chapter 2 dry run. Check one with `uv run army-trainer plan FM-3-09 --check --partial --spec specs/drafts/<file>`.

`FM-3-09.review.json` is the WP 4.1 fidelity review of `FM-3-09.spec.json` (it records the spec's SHA-256: any edit to the spec voids it until it is re-reviewed). Check with `uv run army-trainer qa FM-3-09 --review-check`.
