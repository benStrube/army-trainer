## Not done / known issues
- **Figures:** only the caption is kept (`**Figure 2-1. …**`). Images aren't extracted. Slides draw their own diagrams, so this is low priority. Add cropping if a later WP needs the original figure.
- **Scrambled rows left as-is** on PDF pages 109, 176 and 248 (listed in the report as `table_rows_scrambled_pages`). They are a table footnote and two small rows where the letters didn't match exactly, so they weren't rebuilt.
- **Garbled multi-line table headers** (Tables 3-1, 3-7, 3-10, 3-11) are rebuilt as one cell with stacked labels (`Operations<br>Process<br>…`). The text is faithful, but the column labels aren't split per column.
- **Heading level skips** (e.g. `##` → `####` in Appendix D, where the FM itself goes Section → minor heading with no middle tier). This is faithful to the PDF styles. The doc tree should nest by level, not assume +1 steps.
- Table A-1 and similar checklists have no grid in the PDF, so they come out as paragraphs under their caption.
- Some mid-page dehyphenation by pymupdf4llm drops a hyphen ("airdelivered"). It's rare and wasn't fixed.
- **Telemetry note:** onnxruntime (pulled in by pymupdf4llm's layout model) tries to reach `mobile.events.data.microsoft.com`, and the proxy blocks it. Conversion is unaffected.

## Notes for the next model
- **WP 1.3 should parse the Markdown, not the PDF.** Useful anchors:
  - heading lines `#`…`######`
  - numbered paragraphs `^\**(\d+|[A-E])-\d+\.\**\s`
  - captions `**Table N-N. …**` and `**Figure N-N. …**`
  - page markers `<!-- page N (label) -->`, which give each paragraph its page and printed page
  - glossary lines `**term** — …`
- FMs have **no `a.`/`(1)` sub-paragraph nesting**. Structure is chapter → section → headings → numbered paragraph → bullets (2 levels). Keep the schema general enough for ARs later.
- Defined terms are italic in the text (`_term_ is …`); bold-italic marks FM 3-09 as the term's proponent. That's a free signal for WP 1.4.
- Front-matter `title`/`proponent` come from the converter. `fetch` still leaves `title` and `proponent` null in `meta.json`.
- The FM 3-09 PDF is still at the repo root (10 MB). The integration tests find it there or at `data/raw/FM-3-09.pdf`.
