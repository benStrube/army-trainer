## Notes for the next model
- WP 1.2 should be built as post-processing on pymupdf4llm Markdown, `to_markdown(path, pages=..., header=False, footer=False)`. In v1.28 the `margins=` argument is ignored; use `header`/`footer`.
- Known pymupdf4llm gaps to fix in 1.2:
  - paragraphs split at page breaks
  - "(continued)" tables split per page with the caption repeated
  - bullet cells split into extra rows with an empty first column
  - `<mark>` tags around some headings
- **Use the PDF bookmark tree (`doc.get_toc()`) as ground truth for headings.** It goes down to level 5 in FM 3-09.
- Italic defined terms (`_term_ is …`) survive conversion and are a ready-made glossary/key-terms signal for WP 1.4.
- Don't overfit cleanup rules to FM 3-09. ARs add `a.`/`(1)`/`(a)` nesting, the Summary of Change, and their own glossary layout.
