## Done
- ✅ A renderer for **every one of the 19 patterns** in the slide spec, drawn with native python-pptx shapes on `templates/base.pptx`. The plan only required nine; the rest were added because the FM 3-09 spec uses `comparison`, `decision_tree`, `cycle`, `key_idea`, `big_numbers`, `key_terms` and others, and 3.3 needs them.
  - `render/shapes.py`: `box()` (flat shape with text that shrinks to fit), `line`, `check_mark`, `cross_mark`, `set_title`, `Ctx`.
  - `render/patterns/simple.py`: title, at_a_glance, takeaways, whats_new, divider, key_idea, checklist, big_numbers, comparison, closing.
  - `render/patterns/diagrams.py`: process_flow, cycle, roles, timeline, do_dont, table, decision_tree, key_terms, acronyms.
  - `render/patterns/__init__.py`: `REGISTRY` maps each pattern to a layout and a function.
  - `render/deck.py`: `render_slides(spec, out, template, only=None)` draws slides and returns a `Ctx`.
- ✅ Sample slides from the all-patterns fixture, with thumbnails: `uv run python scripts/render_samples.py` writes `out/samples/` (needs `soffice` and `pdftoppm`).
- ✅ I rendered the whole FM 3-09 spec (37 slides) through LibreOffice and looked at every slide. Layouts hold up. No text is clipped.
- ✅ Tests in `tests/test_render_patterns.py`: the fixture renders with zero fit warnings, FM 3-09 renders, and item text is copied exactly. The suite passes (95 passed, 3 skipped) and lint is clean.

## Not done / known issues
- **Text-fit warnings on FM 3-09:** about 26 boxes end up at their minimum font size and the estimator still thinks they may overflow. Rendered by eye they look fine, so the estimate is conservative. In 3.3, use `Ctx.warnings` to decide when to split a slide. The FM 3-09 test deliberately doesn't assert zero warnings.
- **Small text on dense slides:** dense tables, decision tree nodes and some role cards drop to 13–16 pt, below the 18 pt body target. These are the densest slides in the spec. An Opus-side fix would be to cut the text; the other option is to split the slide.
- **Looks that are simpler than the real thing:** the cycle is a ring plus a numbered legend. Decision trees use straight connectors (no elbow lines). Hierarchy roles show the first duties inside the boxes.
- **Not yet done (3.3):** footers with citations, speaker notes with the verbatim source text, overflow splitting, deck assembly and the CLI `render` command. Footer and slide-number placeholders aren't copied onto slides yet.
- Not opened in real PowerPoint, only LibreOffice.

## Decisions made
- No new project decisions. Two renderer details worth knowing:
  - Shapes zero their theme `effectRef` as well as setting an empty `effectLst`. LibreOffice ignores the empty list and drew shadows.
  - Layout names are the contract with the template: `Title Slide`, `Section Header`, `Content`.
