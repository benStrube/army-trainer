## Notes for the next model (Sonnet, WP 1.4 index extractors)
- **Build on the tree, not on the Markdown or the PDF.** `from army_trainer.structure.parse import parse_markdown` or load the JSON with `DocTree.model_validate_json(...)`. Walk `children` recursively.
- **Use `plain` for matching and keep `cite` / `id` on every index entry**, so the planner can cite it.
- What each extractor gets from the tree:
  - **Directive sentences** (`will`, `must`, `will not`, `may`, `should`): split `plain` of paragraphs, list items and texts into sentences. Keep the exact verb.
  - **Deadlines / time limits:** patterns like "within N days", "no later than", "NLT", "hours".
  - **Roles:** FSCOORD, FSO, FSE, fire support sergeant, forward observer and so on. Start from the Chapter 2 headings under "Fire Support Personnel" and the acronyms list.
  - **Cross-references:** "see table 1-2", "(FM 3-0)", "see chapter 3", "ATP 3-09.50".
  - **Glossary terms:** already `term` nodes. Also collect in-text definitions from italic `_term_ is …` in paragraph `text`.
- **Opus-owned (don't change; hand over instead):** `structure/models.py`, `schemas/*.json`, and the citation rules in `docs/doc_tree.md`. If an extractor needs a new field in the tree, stop and hand over to Opus.
